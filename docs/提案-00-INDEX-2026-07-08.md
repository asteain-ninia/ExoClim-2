### 2.2 相互依存（要追跡リンクの検証結果）

- **T04 → 不採用**: T04 の R=P_annual/Pth 方式は追補で撤回（P3 T04）。撤回理由は (a) 内部境界 2.0/3.5 に文献根拠なし、(b) 冬雨型/寒冷セルで Pth→0 のとき R が発散し中程度降水を very wet と誤判定（P2 T04 レビュー note）。**採用構成は「Step6 ラベル → T05 絶対表 → T02 Köppen 式」で完結**（P3 T04）。→ 本インデックスでは T04 を **不採用**として扱う。
- **T09 ⇔ Cwa は同一物理**: T09 の大陸冬季高気圧（ΔP_max=+26hPa、シベリア高気圧、P2 T09 / P3 T09）と、Cfb/Cwa 設計の Cwa 対処（冬乾燥＝季節コントラスト付与、P5 W-1）は「大陸内部の冬季乾燥・高気圧」という同一の物理を別 Step から扱う。T09=Step4 気流の気圧場、W-1=Step6 降水の冬 dry ラベル。**両者は連結して整合させること**。
- **T08 ⇔ Cfb/Cwa 東西役割分担**: T08（ITCZ 西岸補正）は追補で「東岸が高緯度まで湿潤になる現象は Step6 の暖流海岸 onshore wet トレースが担当、ITCZ 帯をそこまで伸ばすと二重計上」と再構成（P3 T08）。P5 も明示的に「W-1（Step6 東岸の季節コントラスト）は T08 の役割分担（東岸湿潤=Step6 管轄）と整合、T08 は撤回されていない（撤回は T04）」と確認（P5 §3.4）。**西岸湿潤=T08/Step3 暖流連成、東岸湿潤=Step6 管轄**、で二重計上しない。
- **系統2 は T01 を使わない**: 系統2 の Ar=AET/PET は kalike 線形 PET（気温×係数 4.5〜7mm/月/°C）で較正された体系であり、T01 Thornthwaite に差し替えると Pasta 公開図比較が崩れる（P4 §3.1）。**T01 Thornthwaite は系統1 Köppen（T02）向けの任意 backend に留め、系統2=kalike 線形と別物として扱う**（同じ ET 係数を両系統で別意味に流用しない、P4 §5.2）。重複回避が明示的な設計原則。
- **Cfb 根因 ⇔ T01/T02 PET 接続点**: Cfb 過小の主因は topology（西岸海岸山脈・斜め西岸・暖流分類の高緯度中立化）であり補正不足ではない（P5 §2）。系統2 の Ar=AET/PET は T01/T02 の PET 提案と接続点を持つ（PET マップ供給が共通土台、P4 §2.3）が、系統2 は kalike、系統1 は Köppen Pth と backend が分岐する（前項）。
- **T08 → Cfb 入力連成**: P5 は Cfb の入力側母数底上げに「C-2（暖流分類の高緯度中立 60°→65° 緩和）＋ T08 の思想（西岸湿潤=Step3 暖流分類連成、ΔW_warm 1 パラメータ化）」を挙げる（P5 §4）。T08 の追補再構成が Cfb 対処の入力側手段として再利用される。
