## T03 — 長日/短日スケーリング: 飽和形への差し替え

**レビュー指摘の確認**: 正しい。√P則は半無限固体の熱慣性応答（大気なしの表層）であり、実惑星では (a) 大気境界層の熱容量、(b) 夜側への水平移流、(c) P→∞で昼側が放射平衡温度に漸近する上限、の3つがDTRの伸びを頭打ちにする。√Pが成り立つのは短周期側だけ。

**改訂式（Fable推論＋本編既出アンカーで較正）**:

```
k(P) = √( 6P / (P + 120h) )        … P は太陽日（時間単位）
DTR(P) = DTR_base × clamp(k(P), k(3h)≈0.38, √6≈2.45)
```

- 関数形の由来: 短周期極限で k∝√P（熱慣性領域）、長周期極限で k→√6≈2.45 に飽和（放射平衡コントラストの上限）。この2領域を持つ最簡潔な形。
- 較正: 本編アンカーのうち最も信頼できる2点 **P=24h→k=1**（乾燥地基準20°C）と **P=240h→k=2**（昼40°C/夜氷点下≈DTR40°C）を厳密に通る（√(6·24/144)=1、√(6·240/360)=2）。
- 残差の検証: P=120h→k=1.73（34.6°C、実測「>25°C」と整合）。P=48h→k=1.31（26°C、実測15-20°Cより高いが、この点は本編も認める通り「乾燥地」でなく「多くの地域」の値でありアンカー間の地域条件が揃っていない。棄却理由にしない）。P=720h→k=2.27（45°C、実測≈30°Cより高い。ただしこのランは全球凍結傾向＋CO2大幅調整下であり較正域外と扱う）。
- **飽和スケール P_c=120h の物理的解釈（推論）**: 地球型大気の境界層の放射緩和時間は数日オーダーであり、P_c≈5日はその周期換算と桁が合う。ゆえに P_c は「大気の熱応答時間」パラメータとして公開し、**薄い大気ほど短く（火星型: DTR上限へ早く到達）、濃い大気ほど長く（金星型: k≈1のまま）** 調整せよ、という向き付きのチューニング指針を添える。既定 P_c=120h、k上限√6は「1気圧・海洋あり」のPasta実験系に対する値。
- 旧√P則からの移行: 本編の式 k=√(P/24) は P≤24h では新式とほぼ一致する（P=6h: 0.50 vs 0.53）ため、短周期側の挙動は保存される。P_min=3hのガードは維持。

**残る確認事項**: Pasta「Day Length」記事の生値の再照合（実装時にWebFetchで数値表を取り直し、k(48h)の扱いを確定）。

## T04 — 降水ラベル変換: R方式の撤回を推奨

**レビュー指摘の確認**: 正しい。さらに一歩進める——**この論点は解く必要がない**。

**構造的再検討（Fable推論)**: パイプラインを俯瞰すると、ラベル→定量の変換は既に2つの sound な部品で挟まれている:
- **T05（sound）**: ラベル→mm/月の絶対対応表（dry<30 / normal 30-60 / wet 60-180 / very wet>180 mm/月）→ Köppen公式閾値へ接続
- **T02（sound）**: B/D判定はKöppen乾燥限界式 Pth=20×MAT+S を「MAP<Pth か否か」の**片側テスト**として使う

T04のR=P/Pth方式は、この2部品と役割が重複する第3の変換層を新設するものであり、そこで初めて (a) 文献根拠のない内部境界2.0/3.5、(b) Pth≤0での発散、という2つの問題が**発生する**。Köppen原典でPthが発散問題を起こさないのは、Pthを比の分母ではなく片側テストにしか使わないからである。つまりレビューが挙げた2欠陥はどちらも「Pthを分母に転用した」ことの帰結。

**推奨**: R方式（境界2.0/3.5を含む）は**spec昇格候補から外す**。採用構成は「Step 6ラベル → T05絶対表 → T02 Köppen式」で完結させる。将来、乾燥側のラベル判定に気温依存性が欲しくなった場合のみ、発散しない代替として **UNEPアリディティ指数 AI = P_annual / PET_annual**（T01のThornthwaite PETを分母に流用。乾燥側境界 0.05/0.20/0.50/0.65 は本編T04出典欄のFAO資料に既出の公表値）を検討する。湿潤側（wet/very wet）の分割はAI体系にも公式境界がないため、T05の絶対表を正とする。

**帰結**: 創作値も特異点も消え、追加実装ゼロ。本編T04セクションは「検討の記録」として残し、採用しない旨を明記することを推奨。

## T06 — 亜熱帯高気圧の季節移動: √則→線形則へ

**レビュー指摘の確認**: 正しい。それを決定的にする論証を1つ追加する。

**√則の反証（Fable推論）**: 季節移動の物理的上限は太陽直下点の振れ幅＝±εである（強制源より応答が大きく動く機構は存在しない）。√則 shift=5°×√(ε/23.4°) は ε≈1° で shift≈1.03°＞ε となり、**「高気圧帯が太陽より大きく移動する」という物理的に不可能な予測**を低傾斜側で出す。ε→0での微分無限大が原因。関数形として棄却できる。

**改訂式**:

```
shift_amplitude(ε) = δ × ε        … δ = 減衰係数（既定 0.214 = 5.0°/23.4°）
適用域 ε ≲ 40–45°。それ以上は本編どおりレジーム分岐（ITCZ跳び越えモード）へ。
```

- 線形の根拠: 強制（太陽赤緯振幅）が ε に厳密比例し、減衰要因（海洋・地表の熱慣性）は ε に依存しない。したがって中低傾斜域の一次応答は線形。ε=0 で shift=0、勾配有限、常に shift<ε — 3つの物理的境界条件をすべて満たすのは候補中これだけ。
- 高傾斜側: レビューの「線形以上に効く」見立てに同意。ε>40–45°の超線形化・レジーム転移は本編既出のPasta Obliquity記事とGuendelman & Kaspi系の理論に委ね、線形式を高傾斜へ外挿しない（この分岐設計は本編の結論を維持）。
- **δの公開（推論）**: δの正体は表層熱慣性による減衰であり、水惑星（混合層が深い）ほど小さく、陸優勢惑星ほど大きい。地球でも海上の高気圧帯移動≈5°に対し大陸上のITF移動は10°超（本編T07の実測）で、δ実効値は下垫面で0.2〜0.6程度の幅がある。既定0.214（海洋優勢の較正点）、調整範囲0.1〜0.5としてスライダー公開を推奨。

## T08 — ITCZ西岸補正: 外付け係数から内部連成へ

**レビュー指摘の確認**: 正しい。W_max・exp(−d/200km)・海盆30°/90°閾値はいずれも裏付け不能で、35°までの拡張はITCZ（熱帯収束帯）を湿潤亜熱帯Cfaの領分へ越境させている。

**構造的再検討（Fable推論）**: 「大洋西岸で帯が広がる」現象の物理的駆動は**暖水**（貿易風が暖水を西へ寄せ、西岸境界流が暖水を極側へ運ぶ→深い対流が高緯度側まで立つ）。そして **ExoClim-2 は Step 3 で暖流/寒流の per-cell 分類を既に計算している**。ならば距離減衰や海盆幅の代理指標を新発明する必要はなく、既存の内部状態に直結すればよい:

```
width_half(cell) = 15° + ΔW_warm × [そのセル帯域の海洋セルが暖流分類]
既定 ΔW_warm = +5°（Pasta原文 “a bit wider” の読みとして控えめな加算）
上限 = 15°+10°（ΔW_warmの調整上限）。35°まで広げない。
寒流側の狭窄 ΔW_cold は既定0°（Pasta非言及のため）、必要なら負値の調整パラメータとして公開。
```

- **自由係数が3個（W_max, 200km, 30°/90°）→1個（ΔW_warm）に減る**。海盆サイズ依存は「小さい海盆ではStep 3が強い境界流を生成しない」ことで**自動的に**表現される（basin検出とジャイヤ生成が既にゲートしている）。距離減衰は不要 — 帯の内陸浸透はT07（大陸性振幅）の管轄であり、二重に持たない。
- **35°問題の解消**: 大陸東岸が高緯度（25–35°）まで湿潤になる現象は、Step 6 の「暖流海岸 onshore wet トレース」が既に担当している。ITCZ帯をそこまで伸ばすと**同じ物理を二重計上**する。ΔW上限+10°はこの二重計上防止のガード。
- 実装は「ITCZ月次中心緯度に追随して帯全体を平行移動」という本編の方針を維持。

## T09 — 気圧anomaly合成: 正規化で問題を解消

**レビュー指摘の確認**: 正しい。ただし指摘された不確定係数の大半は、**モデルがそもそもhPa絶対値を必要としていない**ことに気づくと消える。

**構造的再検討（Fable推論）**:

1. **正規化実装を主とする**。Step 4 が下流に渡すのは風ベクトルの合成パターンであり、本編の合成式でも anomaly 風速は `V_center = V_belt_typical × (ΔP/ΔP_max)` — つまり **ΔPはΔP_maxとの比でしか効かない**。ならば anomaly 強度を最初から無次元 s = min(1, (|ΔT|−5°C)/ΔT_sat) で持てば、α（hPa/°C）も4系統のΔP_max（hPa）も内部計算から消える。残る自由度は ΔT_sat（飽和までの温度差、既定20°C）と合成比 k のみ。hPa表示はUI用の飾り（s×26hPa等）に格下げする。レビューが「恣意的」とした係数群の大半は、この時点で**検証対象ですらなくなる**。
2. **αは実は導出できる（hPa表示を残す場合）**: 唯一の検証済みアンカー（シベリア高気圧 +26hPa）と、シベリア冬季の陸海温度差の常識値 ΔT≈25–30°C（Fable推論・要一次確認）から α = 26/(25〜30 − 5) ≈ **1.0〜1.3 hPa/°C**。本編の α=1.0 は「恣意」ではなく検証済みアンカーの含意として再位置付けできる。残り3系統のΔP_maxも独立定数ではなく「α×(典型ΔT−5)の予測値」として導出扱いにすれば、夏季ヒートロー（ΔT≈15–20→−10〜−15hPa）・海氷隣接低気圧（同程度）は自動的に本編の推定値圏に落ちる。**独立に検証すべき創作定数が4個→0個**になる。
3. **海洋亜熱帯高気圧はanomaly層から外す**: 4系統のうち海洋亜熱帯高気圧だけは熱的（陸海温度差）ではなく力学的（ハドレー下降流）起源で、**Step 2 の風帯ベースラインが既に配置している**。anomaly層に+11hPaで再登場させるのは二重計上。anomaly層は熱起源の3系統（大陸冬季高気圧・大陸夏季/モンスーン低気圧・海氷隣接低気圧）に限定する。
4. r0=800kmは「平滑化半径」と正直にラベルし、本編適用ノート既出の Ω 反比例スケーリング（ロスビー変形半径∝1/f）を既定の拡張フックとして採用。k=1.0既定は「飽和時にモンスーン反転が完全成立する」規格化点として維持（spec §6.1の利用者調整に対応）。
