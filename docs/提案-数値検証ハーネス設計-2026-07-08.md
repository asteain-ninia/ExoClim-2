## 3. カウント定義の統一（297/309/471/30599 の整理）

### 3.1 揺れの原因

- **解像度が固定されていない**: テストは 1°（[phase41_validation.test.ts:35] 第3引数 `1`）。
  グリッドは 0.5°/1°/2° の三段階（[grid.ts:3]、`latitudeCount = 180/resolutionDeg` [:68]）。
  現状.md §5 の生セル数は app eval 由来で解像度が異なる（0.5° なら総 259200 セル）ため、
  同じ「Cfb セル数」でも母数が 4 倍違う。**471 と 297/309 と 30599 は互いに非可換**。
- **母数（分母）が明記されていない**: 「Dfc 30599=約35%」の 35% が「全 land / 全セル / 特定緯度帯 land」の
  どれか不明。骨組みは `countByPrefix(prefix)/totalLand`（[:83-101]）で **land セル母数**に統一しているが、
  eval 側の百分率はこれと別基準の可能性が高い。**厳密な出自は unknown**（app 描画由来と推定）。

### 3.2 統一定義（本ハーネスの正）

> **CD-1（母数）**: すべての気候帯カウントは **分数 = 対象セル数 / 母数セル数** で表現し、
> 生セル数（471 等）を合格条件に使わない。
> **CD-2（解像度固定）**: フィクスチャは **解像度 1°（180×360）に固定**する
> （[phase41_validation.test.ts:35] 現行踏襲）。回帰の決定性（[開発ガイド.md §4.4]）のため、
> 解像度を変えたら全レンジを再校正する（解像度は暗黙のチューニング変数）。
> **CD-3（母数の種類を明示）**: 母数は用途別に 3 種を定義し、テスト名に必ず含める:
>   - `/ landCells`（全陸セル。[:93-101] `totalLandCells`）— 群レベル比率用
>   - `/ bandLandCells(latLo,latHi)`（特定緯度帯の陸セル）— 帯の地理判定用（#6-8 が既に採用）
>   - `/ coastLandCells(side, latLo, latHi)`（西/東岸 N セル以内の陸）— Cfb/Cs/Cwa の母数律速確認用
>     （[提案-CfbCwa地理拡張設計 §5.1] の「lat 42-60° 西岸母数」測定に対応）
> **CD-4（生セル数はログのみ）**: 診断用に生セル数も出力してよいが、assert には使わない。
> app eval の 471/297/309/30599 は「別解像度の履歴値」として扱い、本ハーネスの目標値に転記しない。

### 3.3 目標値（合格レンジ）の決め方

- 群レベル（A-E）: 現行 #1-5 のレンジを維持（地球実比率の桁感）。
- 帯レベル: **まず CD-3 の `coastLandCells` 母数を測定**（[提案-CfbCwa §5.1]）。
  「Cfb セル / lat 42-60° 西岸母数」が topology 律速で頭打ちなら、目標は「母数の N%」で相対定義する。
  **絶対セル数の目標は母数測定前は unknown**（[提案-CfbCwa §6] と同じ結論）。

### 4.2 回帰の回し方

1. **1係数ずつ（one-at-a-time）を原則**とする。気温系(K2/K5)と気候帯系(K1/K3/K4)は**相互作用が強い**
   （K2 を動かすと D/E 境界が動き K4 の効きが変わる）ため、同時変更は交絡して原因切り分け不能になる。
   [開発ガイド.md §4.4] の決定性要件とも整合。
2. **順序（推奨）**: 上流→下流。①K2/K5（気温の物理妥当性 = #9/#10/#11 を先に固定）→
   ②K1/K3/K6（B 群・降水由来）→③K4/K7/K9（C/D/A 境界）→④K8（post-process で残差整形）→⑤系統2 K10。
   上流を固定せずに post-process(K8) を回すと「入力の歪みを後処理で糊塗」して脆くなる（[提案-CfbCwa §4] の教訓）。
3. **各ステップで fingerprint を撮る**: 変更前後で「群比率＋主要帯セル数（診断ログ）」を記録し、
   意図した指標だけが動き他が動いていないことを確認（意図せぬ相殺 = 現状.md §5 5th eval「EF/ET 副作用で相殺」の再発防止）。
4. **trade-off は明記して受容**: K5 の Dfc↓ と E↑ のような相殺は 1 係数で両立不能。
   「どちらの指標を優先するか」を先に決め、レンジを非対称に設定する（例: E は上限を緩めに）。
5. **Cfb/Cwa は係数でなく構造で対処**（[提案-CfbCwa §0]）: Cfb 過少は topology 律速 → K8(C-1) 受容 + 暖流連成、
   Cwa 過少は上流(06)の季節コントラスト改善(W-1)。**しきい値 K7 を緩めない**（Pasta 定義から乖離）。

本ハーネス設計に効く [開発ガイド.md §6] の教訓と適用:

- **§6.1.1 -0 と `toBe(0)`**: 退化ケース（E10/E11、軸傾斜0・海洋率0）で `-x*cos()` が -0 を返す。
  気温/降水の 0 判定は必ず `expect(Math.abs(v)).toBe(0)` か `toBeCloseTo(0,n)`。群比率も 0 群セルの分数で -0 が出うる。
- **§6.1.2 線形 insolation→温度の破綻**: K2(ANNUAL350/SEASONAL80)を動かすときは
  極夏/赤道夏/極冬/赤道冬の 4 隅を手計算検証してからレンジ調整。E8/E9 の polar 帯レンジは
  SEASONAL 過大で E が暴走・消失しうる（#8 が >75°過半→>10% に緩和済[:171-176]の経緯を踏襲）。
- **§6.3.2 指紋テストの感度低下**: E12 の fingerprint は「明確に大きな差分が出る方向」で書く
  （very_wet を**下げる**より**上げる**、境界クランプに注意）。粗いカウントは小変化を drowned out するため、
  対象群だけでなく「他群が動かないこと」も併せて assert して感度を担保。
- **§4.4 決定性**: フィクスチャ・解像度・係数を固定（CD-2）。乱数 seed 依存（procedural 地形）を持ち込まない。
  idealized_continent は preset なので決定的（[terrain.ts:226] 純粋関数）。
- **T04 撤回の反映**: label→mm は R=P/Pth 方式を採らず、T05 絶対表 + T02 片側テストで判定
  （[追補-needs_check再検討 T04]）。K1 のレンジ根拠を R 倍数（2.0/3.5）で書かないこと。
